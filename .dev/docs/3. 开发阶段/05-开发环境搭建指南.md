### 3. JDK 安装

#### 3.1 macOS（SDKMAN）

```bash
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 17
sdk use java 17
```

#### 3.2 Windows

1. 下载 Temurin 17 MSI
2. 设置 `JAVA_HOME` 环境变量
3. `PATH` 追加 `%JAVA_HOME%\bin`
4. 验证：`java -version`

### 4. Maven 配置

`~/.m2/settings.xml`：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
  <profiles>
    <profile>
      <id>default</id>
      <activation><activeByDefault>true</activeByDefault></activation>
      <properties>
        <java.version>17</java.version>
      </properties>
    </profile>
  </profiles>
</settings>
```

### 6. Git 配置

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
git config --global core.autocrlf input   # macOS / Linux
git config --global core.autocrlf true    # Windows
git config --global pull.rebase true
```

推荐 SSH 免密登录，详见 [Git 提交规范](06-Git 提交规范.md)。

### 7. 本地中间件（Docker Compose）

`docker-compose.yml`：

```yaml
version: "3.8"
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: minimall_dev
    ports: ["3306:3306"]
    volumes: ["./data/mysql:/var/lib/mysql"]

  redis:
    image: redis:7.2.4
    ports: ["6379:6379"]

  nacos:
    image: nacos/nacos-server:2.3+
    ports: ["8848:8848"]
    environment:
      MODE: standalone
```

启动：`docker compose up -d`

### 8. 拉取代码与构建

```bash
git clone git@github.com:org/minimall.git
cd minimall
./mvnw clean install -DskipTests
```

### 9. 启动应用

```bash
# 默认 profile = dev
./mvnw spring-boot:run

# 切换 profile
./mvnw spring-boot:run -Dspring-boot.run.profiles=prod

# 直接运行 jar
java -jar target/minimall.jar --spring.profiles.active=dev
```

### 10. 验证清单

- [ ] `java -version` 显示 17
- [ ] `mvn -version` 显示 3.8.6
- [ ] `git --version` 显示 2.40+
- [ ] `docker ps` 能看到 mysql/redis/nacos
- [ ] IDEA 能导入项目并识别 Lombok
- [ ] `./mvnw clean compile` 成功
- [ ] `./mvnw test` 全部通过
- [ ] 应用启动后 `curl localhost:8080/actuator/health` 返回 UP
- [ ] 访问 `localhost:8848/nacos` 能登录

### 11. 常见问题

| 问题 | 解决方案 |
|------|----------|
| `JAVA_HOME not set` | 配置环境变量并重启终端 |
| Maven 下载慢 | 配置阿里云镜像 |
| Lombok 不生效 | IDEA 装 Lombok 插件 + 开启注解处理 |
| 端口占用 | `lsof -i:8080` / `netstat -ano` |
| Docker 启动失败 | 检查 Docker Desktop 是否运行 |
| git CRLF 警告 | 设置 `core.autocrlf` |
