## 文档目的

> 明确各环境（dev / test / staging / prod）的配置差异、敏感信息管理方式与环境隔离原则。

## 适用范围

- **适用对象**：研发、运维、SRE
- **适用场景**：新环境搭建、配置变更、问题排查
- **不适用范围**：纯开发配置（见 [开发环境搭建指南](../3.%20开发阶段/05-开发环境搭建指南.md)）

## 详细内容

### 1. 环境清单

| 环境 | 用途 | 域名 | 数据 | 访问控制 |
|------|------|------|------|----------|
| dev | 本地开发 | localhost | 共享 dev DB | 开发 |
| test | 集成测试 | test.example.internal | H2 / Testcontainers | 测试 |
| staging | 预发验证 | staging.example.com | 脱敏生产数据 | 运维 + 产品 |
| prod | 生产 | api.example.com | 生产数据 | 严格审批 |

### 2. 配置分层

```
application.yml           # 公共配置
├── application-dev.yml    # 开发
├── application-test.yml   # 测试（H2）
├── application-staging.yml# 预发
└── application-prod.yml   # 生产
```

激活方式：
- 启动参数：`--spring.profiles.active=prod`
- 环境变量：`SPRING_PROFILES_ACTIVE=prod`
- K8s：ConfigMap + 环境变量注入

### 5. 敏感信息管理

#### 5.1 禁止行为

- ❌ 敏感信息写入 yml / properties / 代码
- ❌ 提交到 Git 仓库
- ❌ 在聊天工具明文传输

#### 5.2 推荐方案

| 方式 | 适用 |
|------|------|
| 环境变量 | 容器化部署 |
| Nacos / Apollo | 集中管理 + 热更新 |
| Vault / KMS | 高度敏感（DB 主密码、支付密钥） |
| Spring Cloud Config + 加密 | 中等敏感度 |
| K8s Secret | 容器编排场景 |

#### 5.3 密钥轮转

| 密钥 | 轮转周期 |
|------|----------|
| 数据库密码 | 90 天 |
| API 密钥 | 180 天 |
| 支付密钥 | 30 天 |
| JWT 签名密钥 | 90 天 |
| 证书 | 到期前 30 天 |

| 组件 | dev | test | staging | prod |
|------|-----|------|---------|------|
| MySQL | 8.0 | H2 | 8.0 | 8.0 |
| Redis | 7.2.4 | Testcontainers | 7.2.4 | 7.2.4 Cluster |

### 7. Druid 连接池配置

#### Druid 连接池参数

| 参数 | 值 | 说明 |
|------|-----|------|
| initialSize | 5 | 初始连接数 |
| minIdle | 5 | 最小空闲连接 |
| maxActive | 20 | 最大连接数 |
| maxWait | 60000 | 获取连接超时（毫秒） |
| timeBetweenEvictionRunsMillis | 60000 | 检测间隔 |
| minEvictableIdleTimeMillis | 300000 | 空闲检测（毫秒） |
| validationQuery | SELECT 1 | 连接有效性检测 |
| testWhileIdle | true | 空闲时检测 |
| testOnBorrow | false | 获取时不检测 |
| testOnReturn | false | 归还不检测 |

配置示例：
```yaml
spring:
  datasource:
    druid:
      initial-size: 5
      min-idle: 5
      max-active: 20
      max-wait: 60000
      time-between-eviction-runs-millis: 60000
      min-evictable-idle-time-millis: 300000
      validation-query: SELECT 1
      test-while-idle: true
```

#### 慢 SQL 监控

Druid StatFilter 配置慢 SQL 阈值 1 秒：

```yaml
spring:
  datasource:
    druid:
      filter:
        stat:
          enabled: true
          slow-sql-millis: 1000
          log-slow-sql: true
```

超过 1 秒的 SQL 记录到日志，便于排查优化。

### 8. MySQL 连接数配置

确保 MySQL 实例配置 `max_connections=500`（或更高）。

计算依据：10 个 schema × 每服务最大 50 连接（Druid `max-active`）= 潜在 500 并发连接。MySQL 8.0 默认 `max_connections=151`，不足以支撑多服务并发连接池需求，必须在 MySQL 服务端 `my.cnf` 中调大。

```ini
# my.cnf
[mysqld]
max_connections = 500
```

### 9. 网络与端口

| 服务 | 端口 | 协议 | 暴露 |
|------|------|------|------|
| 应用 | 8080 | HTTP | 内网（通过 LB 对外） |
| Actuator | 同 8080 | HTTP | 内网 |
| MySQL | 3306 | TCP | 内网 |
| Redis | 6379 | TCP | 内网 |
| Nacos | 8848/9848 | HTTP/gRPC | 内网 |

- 生产环境**禁止**直接暴露 DB / Redis 端口
- 仅 LB / API Gateway 对外开放 443

### 10. 环境隔离原则

- dev / staging / prod **禁止**共用 DB、Redis、MQ
- **禁止** prod 环境的访问凭证出现在 dev / staging
- **禁止** dev / staging 域名带 `prod` 字样
- **禁止** dev 环境直连 prod 数据
- **禁止** prod 集群执行破坏性操作未审批

### 11. 反模式（禁止）

- ❌ 生产配置进 Git
- ❌ 跨环境共用配置中心 namespace
- ❌ 测试环境跳过审批直接走生产网络
- ❌ `.env` 文件提交到仓库
