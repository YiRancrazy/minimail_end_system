## 1. 系统概述

- **系统名称：** `minimall`
- **核心功能：** B2C电商：商品/订单/支付/库存/通知
- **用户角色：** 平台管理员、商家、消费者
- **技术栈：** Java 17、Spring Boot 3.2.x、MyBatis-Plus、Redis、MySQL 8.0 等

---

## 2. 环境要求

### 2.1 运行环境

| 软件/组件     | 版本要求          | 备注                              |
|---------------|-------------------|-----------------------------------|
| JDK           | 17                    | 生产环境推荐使用 LTS 版本     |
| MySQL         | 8.0                  | 字符集统一使用 `utf8mb4`        |
| Redis         | 7.x                  | 哨兵或集群模式按需配置        |
| Nacos/Apollo  | 2.3+                  | 配置中心                      |
| Nginx         | 1.24+                  | 反向代理                      |
| Maven/Gradle  | 3.8.6                  | 构建工具                      |

### 2.2 数据库初始化

执行以下脚本完成库表创建：

```sql
-- 库名：minimall_db
CREATE DATABASE IF NOT EXISTS minimall_db DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;

-- 示例表：订单表（表名使用小写+下划线）
CREATE TABLE `order_info` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键',
  `order_no` varchar(64) NOT NULL COMMENT '订单编号',
  `user_id` bigint(20) NOT NULL COMMENT '用户ID',
  `status` tinyint(4) NOT NULL DEFAULT '0' COMMENT '状态 0-待支付 1-已支付 2-已取消',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_order_no` (`order_no`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单表';
```

## 3. 部署架构

- **网关层：** Nginx / Spring Cloud Gateway  
- **服务层：** 多个 Spring Boot 微服务，注册至 Nacos  
- **中间件：** Redis（缓存）、RocketMQ（异步消息）、Elasticsearch（搜索）  
- **存储层：** MySQL 主从 + MyBatis-Plus  
- **监控：** Prometheus + Grafana + SkyWalking

## 4. 安装部署

### 4.1 获取代码

```bash
git clone git@gitlab.internal:minimall/<service>.git
cd minimall-<service>
git checkout release/v1.0.0   # 分支命名：feature/xxx、hotfix/xxx
```

### 4.2 编译构建

```bash
mvn clean package -DskipTests -P prod -Dbuild-version=1.0.0
# 产物位于 target/minimall-<service>.jar
```

### 4.3 配置文件准备

将 `src/main/resources/application.yml` 中需要根据环境变动的配置项外挂到配置中心（Nacos/Apollo），本地只保留最小配置。

**本地 bootstrap.yml 示例：**
```yaml
spring:
  application:
    name: minimall-<service>
  cloud:
    nacos:
      config:
        server-addr: ${NACOS_ADDR:127.0.0.1:8848}
        file-extension: yml
        namespace: ${NACOS_NAMESPACE:public}
        group: DEFAULT_GROUP
```

### 4.4 启动服务

```bash
java -Xms2g -Xmx2g -XX:+UseG1GC -Dspring.profiles.active=prod -jar minimall-<service>.jar > /dev/null 2>&1 &
```

**JVM 参数建议：** 生产环境必须设置 `-Xms` 与 `-Xmx` 一致，防止内存动态调整带来的性能损耗。（规约推荐）

### 4.5 停止服务

```bash
# 通过优雅停机接口（Actuator shutdown）
curl -X POST http://localhost:8080/actuator/shutdown
# 或 kill -15 PID，确保实现 Graceful Shutdown
```

## 5. 配置说明

| 配置项                                      | 必填 | 默认值          | 说明                               |
|---------------------------------------------|------|-----------------|------------------------------------|
| `spring.datasource.url`                    | 是   | -               | 数据库连接地址，需包含时区参数      |
| `spring.datasource.username`               | 是   | -               | 数据库用户名                       |
| `spring.redis.host`                        | 是   | 127.0.0.1       | Redis 地址                         |
| `minimall-<service>.order.expire-minutes`        | 否   | 30              | 订单超时分钟数（自定义配置用小写短横线） |
| `logging.level.com.yirancrazy.minimall`            | 否   | info            | 日志级别，包路径为服务根包           |

## 7. 监控与告警

- **应用指标：** 通过 `/actuator/prometheus` 暴露 Prometheus 指标。  
- **链路追踪：** 集成 SkyWalking，TraceId 可在日志中输出便于排查。  
- **日志监控：** 日志文件建议使用 `logback-spring.xml` 配置，按天滚动，保留 15 天。
- **告警规则：** 错误率 > 1%、接口 P99 耗时 > 500ms、JVM 堆内存使用率 > 80% 时触发告警。

---

## 8. 日志管理

- **日志框架：** SLF4J + Logback（规约强制使用 SLF4J API）  
- **日志文件路径：** `/data/logs/minimall-<service>/`  
- **日志格式：** `%d{yyyy-MM-dd HH:mm:ss.SSS} [%X{traceId}] [%thread] %-5level %logger{36} - %msg%n`  
- **关键日志输出要求：**  
  - 捕获异常时必须记录完整堆栈（使用 `log.error("xxx", e)` 形式，严禁只打印 `e.getMessage()`）。  
  - 敏感数据（手机号、身份证、密码）必须脱敏后再输出。

**日志级别动态修改：**
```bash
# 通过 Actuator 修改根包日志级别为 debug，无需重启
curl -X POST http://localhost:8080/actuator/loggers/com.yirancrazy.minimall -d '{"configuredLevel":"debug"}' -H "Content-Type: application/json"
```

## 9. 备份与恢复

### 9.1 数据库备份

```bash
mysqldump -u root -p --single-transaction --databases minimall_db | gzip > minimall_db_$(date +%Y%m%d%H%M).sql.gz
```

### 9.2 应用恢复

1. 停止当前服务；  
2. 恢复数据库备份；  
3. 使用相同的 jar 包和配置重新启动。

## 10. 常见问题（FAQ）

| 现象                           | 可能原因                     | 解决方案                                       |
|--------------------------------|------------------------------|------------------------------------------------|
| 启动报错 `Data source not found` | 数据库配置缺失或地址不通     | 检查 Nacos 配置中心数据库相关配置               |
| 接口返回 502 或超时             | 上游服务不可用或负载过高      | 查看 SkyWalking 追踪链，检查依赖服务健康状态     |
| 订单状态不更新                  | MQ 消费堆积或异常被吞        | 检查 RocketMQ 控制台消费者位点，查看异常日志     |
| 内存持续增长且不释放            | 可能存在内存泄漏或缓存过大    | dump 堆内存分析，检查缓存 TTL 设置              |
